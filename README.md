# CachyOS dotfiles

Переносимый снимок пользовательской настройки CachyOS/Niri: конфиги, хоткеи и инструменты скриншотов/записи/OCR/приватности.

## Установка

```bash
./install.sh
```

Для установки только конфигов:

```bash
SKIP_PACKAGES=1 ./install.sh
```

Установщик подставляет `$HOME`, делает резервные копии существующих файлов с суффиксом `.bak.<дата>`, создает `Pictures/Screenshots` и `Videos` и не переносит учетные данные, историю, браузерные профили, кеши, медиа или бинарники.

Для записи региона нужны `wf-recorder`; для OCR — `grim`, `slurp`, `tesseract`, `wl-clipboard`; для интерфейса скриншотов/оверлея — Python GTK/Cairo/GtkLayerShell зависимости. Бинарник `voxtype` намеренно не включен: положите совместимый бинарник в `~/.local/bin/voxtype` отдельно.
